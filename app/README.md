# `app/` — vendored ADK scaffold (not filmIQ)

This directory is the stock **google-adk** starter template generated by `agents-cli`, retained only as the Agent Runtime deploy wrapper. `agent.py` is the unmodified demo agent (a weather/time toy) and is **not** part of filmIQ's scoring pipeline.

**The real entry point is `filmiq_app.py`** at the repo root (`uv run adk web filmiq_app`), which wraps `orchestrator_agent` from `orchestrator.py`. The scoring sub-agents live in `agents/`.

`agent_runtime_app.py` is the deploy wrapper (`AgentEngineApp`), exercised by `test_agent_runtime_app.py` independently of which agent sits behind it.

**Known gap:** `agents-cli-manifest.yaml` sets `agent_directory: "app"`, so the agents-cli deploy target still points at this scaffold rather than the filmIQ orchestrator. Tracked separately.
